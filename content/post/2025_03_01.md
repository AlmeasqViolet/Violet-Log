## 前言

RIFE 在 Linux 下好像并没有什么现成的方案，除了付费的 SVP 可以使用 RIFE 简单地实时补帧，现有的教程好像也很少。正好我最近配置好了 RIFE，写一篇教程送给还在思考要怎么配置 RIFE 的各位。教程时效可能会跟随软件更新而变化，而且在没有一个简单开源的一键配置方法之前，在未来此教程所说方法中的很多细节都可能会变化，所以感觉这篇教程最大的意义是参考。

我使用的是 **Arch Linux**，其他 Linux 发行版的操作可能有所不同，但应该可以当作参考。而显卡方面，NVIDIA/AMD/INTEL三家显卡都有过测试，均可以稳定运行，个人看来，目前性能排名是NVIDIA>INTEL>AMD。（AMD由于MIGX后端暂不支持RIFE故垫底，未来可期；）

### 稳定补帧所支持最高版本（实测，仅供参考——2026年10月更新）

| 显卡 | 版本 | 帧数 |
| :--- | :--- | :--- |
| RTX4060 | 4.26 | 48 FPS |
| RTX4060Ti | 4.26 | 48 FPS |
| RX7700XT | 4.15 Lite | 48 FPS |
| RX7900XT | 4.25 Lite | 48 FPS |
| A750 | 4.25 Lite | 48 FPS |

## NVIDIA

### 1、安装所需软件

```bash
paru -S mpv-full-git vapoursynth-plugin-mlrt-trt-runtime-git vapoursynth-plugin-mlrt-ext-models-rife
```
### 2、编辑配置文件

`rife.vpy`

```bash
nvim ~/.config/mpv/vs/rife.vpy
```

```bash
import vapoursynth as vs
from vapoursynth import core
import vsmlrt

clip = video_in

#向上取整：1920*1080>===>1920*1088
w, h = clip.width, clip.height
w = ((w + 63) // 64) * 64
h = ((h + 63) // 64) * 64
#向下取整：1920*1080>===>1920*1024
#w, h = clip.width, clip.height
#w = (w // 64) * 64
#h = (h // 64) * 64

clip = core.resize.Bicubic(
    clip, 
    width=w, 
    height=h, 
    format=vs.RGBS,
    matrix_in_s="709"
)

clip = vsmlrt.RIFE(
    clip,
    model=46,
    multi=2,
    backend=vsmlrt.Backend.TRT(
        device_id=0,
        workspace=None,
        engine_folder="/home/username/.cache/vsmlrt",
        num_streams=4,
        max_aux_streams=2,
        fp16=True,
        force_fp16=True,
        use_cuda_graph=True,
        #use_cublas=True,
        #use_cudnn=True,
        #use_edge_mask_convolutions=True,
        #use_jit_convolutions=True,
        #static_shape=True,
        #heuristic=True,
        #short_path=True,
        #builder_optimization_level=5,
        #tiling_optimization_level=2,
    )
)

clip = core.resize.Bicubic(
    clip, 
    format=vs.YUV420P10,
    matrix_s="709"
)

clip.set_output()

#模型版本
#补帧倍速
#使用的后端
#使用的显卡序号：0=第一张显卡
#分配显存的大小：None=自动
#编译完成的模型的保存路径
#显卡线程数：1~8
#最大辅助流数：1~8
#是否使用fp16加速：提升性能但会轻微降低质量
#强制使用fp16精度
#是否使用cuda加速
#是否使用cuBLAS库：优化矩阵运算
#是否使用cuDNN库：优化卷积神经网络
#是否使用边缘掩码卷积：降低性能但减少模糊和重影
#是否使用即时编译卷积：提升性能但会增加编译时间
#是否使用静态形状：提升性能但会增加编译时间
#是否使用启发式算法：TRT自动选择最佳算法
#是否使用短路径优化：减少重复计算
#构建器优化等级：0~5
#平铺优化等级：0~2

#查看模型列表
#python3 -c "import sys;sys.path.append('/usr/lib/vapoursynth');import vsmlrt;[print(f'{m.value:>4} = {m.name}') for m in vsmlrt.RIFEModel]"

#查看后端列表
#python3 -c "import sys; sys.path.append('/usr/lib/vapoursynth'); import vsmlrt; print(*[b for b in dir(vsmlrt.Backend) if not b.startswith('_')], sep='\n')"
```

## INTEL

### 1、安装所需软件

```bash
paru -S openvino openvino-intel-gpu-plugin vapoursynth-plugin-mlrt-ext-models-rife mpv-full-git
```


```bash
#I卡vs-mlrt内容AUR不存在，且Github仓库为过时的API3版本，此处使用第三方的API4移植版。
git clone --depth=1 https://gh-proxy.com/https://github.com/RyougiKukoc/vs-mlrt-api4.git
cd vs-mlrt-api4

#编译插件
cmake -S vsov -B build -G Ninja \
  -D CMAKE_BUILD_TYPE=Release \
  -D CMAKE_CXX_FLAGS="-ffast-math -march=x86-64-v3" \
  -D VAPOURSYNTH_INCLUDE_DIRECTORY=/usr/include/vapoursynth \
  -D OpenVINO_DIR=/usr/lib/cmake/openvino \
  -D ONNX_DIR=/usr/lib/cmake/ONNX \
  -D protobuf_DIR=/usr/lib/cmake/protobuf
cmake --build build

#安装插件
install -Dm755 build/libvsov.so \
  "$(python3 -c 'import vapoursynth;print(vapoursynth.get_plugin_dir())')/libvsov.so"
install -Dm644 scripts/vsmlrt.py \
  "$(python3 -c 'import sysconfig;print(sysconfig.get_paths()["purelib"])')/vsmlrt.py"

#验证安装
python3 -c "import vapoursynth as vs; print(vs.core.ov.AvailableDevices())"
```

> 提示：如果想使用 pacman 管理，可以把自己编译好的`libvsov.so`、`vsmlrt.py`和模型目录打成一个本地包再`pacman -U`装进去，`depends`里写上`openvino`和`openvino-intel-gpu-plugin`。这样`openvino`可以正常跟着`pacman -Syu`升级。

### 2、编辑配置文件

`rife.vpy`

```bash
nvim ~/.config/mpv/vs/rife.vpy
```

```bash
import fractions

import vapoursynth as vs
from vapoursynth import core
import vsmlrt

clip = video_in

w, h = clip.width, clip.height
pad_w = (-w) % 128
pad_h = (-h) % 128

clip = core.resize.Bicubic(
    clip,
    format=vs.RGBS,
    matrix_in_s="709"
)

if pad_w or pad_h:
    clip = core.std.AddBorders(clip, right=pad_w, bottom=pad_h)

clip = vsmlrt.RIFE(
    clip,
    model=vsmlrt.RIFEModel.v4_25_lite,
    multi=2,
    backend=vsmlrt.Backend.OV_GPU(
        device_id=0,
        fp16=True,
        num_streams=2,
    )
)

if pad_w or pad_h:
    clip = core.std.CropAbs(clip, width=w, height=h)

try:
    _src_fps = float(container_fps)
except NameError:
    _src_fps = 0.0

if _src_fps > 0:
    _fps = fractions.Fraction(_src_fps).limit_denominator(1001)
    _num, _den = _fps.numerator * 2, _fps.denominator
    clip = core.std.AssumeFPS(clip, fpsnum=_num, fpsden=_den)
    clip = core.std.SetFrameProp(clip, prop="_DurationNum", intval=_den)
    clip = core.std.SetFrameProp(clip, prop="_DurationDen", intval=_num)

clip = core.resize.Bicubic(
    clip,
    format=vs.YUV420P10,
    matrix_s="709"
)

clip.set_output()

#模型版本
#补帧倍速
#使用的后端
#使用的显卡序号：0=第一张显卡
#是否使用fp16加速：提升性能但会轻微降低质量
#显卡线程数（OpenVINO 的流数）：1~8。mpv 是逐帧串行喂帧的，
#多流没有第二个请求可以重叠，基本没有收益，保持 1 就行（只多占显存）。

#查看模型列表
#python3 -c "import vsmlrt;[print(f'{m.value:>4} = {m.name}') for m in vsmlrt.RIFEModel]"

#查看后端列表
#python3 -c "import vsmlrt;print(*[b for b in dir(vsmlrt.Backend) if not b.startswith('_')],sep='\n')"
```
